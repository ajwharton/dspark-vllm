# PIP-200 — DSpark draft-loader silent 12-tensor drop fix (M2)

## Capability
Fix a silent correctness regression in the DSpark draft-weight loader: 12
shared-expert tensors are dropped at load, dropping DSpark acceptance from
~60% to ~25% with no error surfaced. This is the highest-priority M2
correctness item (silent, measurable, blocks real DS4F use).

## Root cause (from audit / PORT-INVENTORY)
The draft loader does not load the shared-expert tensors; the loss is silent
(the loader neither errors nor warns), so a healthy-looking server runs at
~25% acceptance.

## Deliverables (extracted against the chosen base)
1. Patch the DSpark draft weight loader to load the 12 shared-expert tensors.
2. Add a load-time assertion/warning so a future drop is loud, not silent (so
   the class of bug is fixed, not just this instance).
3. Harness probe to measure DSpark acceptance (accept-probe) and flag a
   regression.

## Acceptance (NO-NERF-GATE)
- DSpark acceptance restored to ~60%-class (not ~25%) via harness acceptance
  probe.
- Decode tok/s not regressed below gate threshold.
- Loader now surfaces any further tensor-drop loudly (test added to canonical
  suite).

## Status: spec
Top M2 priority. The concrete unified diff must be extracted from the
community correctness patch (tonyd2wild family; audit-confirmed) and landed as
`pip-200.patch`. Rerolled against whichever base is chosen for `stable`.
